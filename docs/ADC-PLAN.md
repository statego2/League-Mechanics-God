# ADC Mechanics God — redesign plan for Terra

**Status: design ready for implementation; current prototype rejected by the user.**
**Reviewed:** 17 November 2026. **Source baseline:** `codex/adc-mode` at `c1bf897`, gameplay build `0f5a05f44ca3`. This replaces the stale plan based on `main` at `7de3430`. The current source already contains the developed Dodge roster and an isolated ADC prototype. Do not restart from old `main` or copy another game's implementation.

Read `AGENTS.md`, `PROJECT_BLUEPRINT.md`, `README.md`, the latest `docs/PROGRESS.md`, and this plan before coding. The latest owner direction takes precedence over the older full-Ahri Mechanics Arena design. This planning pass changes no runtime. Terra implements in a later session using `ADC_NEXT_AI_PROMPT.md`.

## 1. Outcome and authority

**User requirements:** ADC Mechanics God occupies the existing second mode; control a visibly recognizable Tristana; kite durable, damageable enemies with the familiar A + click attack interaction; punish close contact heavily; combine this with the **same recognizable enemy champions and skillshot families already present in Dodge**. Most enemies pursue, some hold distance and cast. Syndra needs an ADC-specific behavior, rather than reproducing the described two-Q encounter. Preserve Dodge absolutely.

The rejected result is useful engineering groundwork, not an accepted product. A name tag above a generic vector gunner and a few late casts do not satisfy the request. Neither a passing test suite nor a bot winning ten kills establishes visual fidelity or the desired simultaneous kite-and-dodge experience.

**Plan defaults, not additional user mandates:** retain autos + Flash, four-hit ordinary enemies, existing attack timing, a compact encounter controller, and the current arena. Default the redesigned player-facing run to continuous survival with replacements until death; retain ten kills as an internal bounded verification milestone. This follows the requested ongoing Dodge-like pressure without adding another menu mode. Do not claim the user explicitly specified an endless ADC scoring system. Avoid inventory, levelling, a full Tristana QWER kit, new maps, multiplayer, engine migration, or a general combat framework.

## 3. Hard isolation boundary

Use a small ADC-only configuration/encounter block and explicit ADC adapters in the existing vanilla Canvas app. A separate file is optional if it makes the boundary clearer; do not extract the whole engine. A few short mode-specific adapters are preferable to changing mature Dodge scheduling.

- **Do not modify Dodge tuning, spell objects, visitor scheduling, aim distribution, escape policies, Syndra plans/frequency, HP/regen, controls, records, scoring, rendering or assets.** Preserve existing constants and call paths, including `REFERENCE_SPELLS`, `DODGE_*`, `SYNDRA*`, and the rare-encounter policies. Read shared constants; clone ADC configs before changing values.
- Do not call `updateDodgeDirector`, `spawnDodgeVisitor`, `spawnSyndra`, `updateSyndraStay`, `spawnLuxR`, `spawnXerathQ/W`, `spawnOriannaR`, `spawnCassioR` or `spawnMalphiteR` as ADC schedulers. They depend on Dodge director state, visits, bookkeeping and fairness assumptions. Do not create a fake `dodgeDirector` to make ADC work.
- `releaseEnemy` can release the five ordinary projectile families, but its visitor bookkeeping is Dodge-only. An ADC wrapper can set pending cloned spell data, call the existing release path where verified safe, then attach ADC ownership and `spellName` to the produced shot. Audit returning-orb, split and hook lifecycle branches before reuse. Do not globally add visitor flags or make reference identity comparisons point at mutable ADC configs.
- The existing rare hazard update branches often dereference `dodgeDirector`. Create ADC-owned hazard update paths before those branches, with early `continue`; reuse neutral geometry and visual primitives when safe. Similar visual flags alone are not permission to run Dodge state transitions.
- Give each ADC cast a cast ID, caster ID, owner mode and phase. Count its whole multi-phase threat once for concurrency. Keep ADC accounting separate from `recordDodgeOutcome`; do not pollute Dodge records.
- Shared neutral helpers such as `world.path/clip`, `fire`, swept collision, `drawChampion`, `drawDarkSphere` and beam/cone geometry may be called unchanged. If a shared helper needs a new argument, its old default must remain byte-for-byte equivalent in behavior and receive a focused regression. Prefer ADC-only render dispatch over changing existing profile outputs.
- Reset/pause/death/mode changes clear ADC state, attack preset overrides and UI changes. Verify Dodge → ADC → Dodge, including attack timing, awareness, sound, results and restart. Compare same-seed Dodge traces against this baseline with controlled randomness; normal Dodge restarts intentionally randomize seeds.

## 4. Visual acceptance comes first

Create a local transparent Tristana sprite with unmistakable small yordle proportions, large pointed ears, blue/lavender skin, pale hair and a disproportionately large cannon. Match the arena's elevated three-quarter view. Use existing image-generation tooling/skill or a resource with established reuse permission; document provenance in `assets/README.md` during implementation. No ripped sprites, copied external-game bundles, paid dependency or remote runtime asset requirement. Generated fan art is not an official Riot model.

The first art checkpoint must show the actual canvas at normal browser scale, not only a large asset preview. Inspect idle, moving both directions, attack windup, muzzle release/recoil and hit feedback. Transparent bounds must not make her tiny; feet/shadow must align with the collision anchor. A single well-made pose with mirroring and small animation is acceptable initially if identity and attack timing read clearly. Multiple directions can follow only if needed for readability. The old vector can remain an asset-load fallback, but a missing image/fallback is a failed visual gate.

Acceptance: with the name tag hidden in a test capture, the character is visibly Tristana-like and the cannon is readable among enemies. At actual gameplay scale, attacks originate plausibly from the cannon, recoil occurs on release, movement is clear, and enemy attacks remain visible. Do not declare subjective user acceptance without their feedback; record what was actually inspected and provide the captures.

### Syndra ADC cycle (design default)

Hold a catchable stand-off band; use **one Q → recovery → reposition**, with an occasional **one Q → E sphere push → longer recovery** replacing that cycle. Never two Qs in one cycle. The Q point and E direction lock before their respective releases; no post-lock homing. Start with solo Q twice as likely as Q→E, with no consecutive combos; these are proposed tuning values. Keep her alive and attackable throughout, and expose at least a full auto cycle after the attack resolves. Her recovery cannot continuously evade every auto.

Reuse the visible sphere formation, wave and pushed-sphere language. Use ADC-owned state and damage. For the initial ADC variant, retain the push on sphere hit but omit the long stun; document this deliberate training variation and preserve Dodge's push+stun unchanged. Apply cone/sphere damage at most once for the same E. New threats wait through displacement plus recovery; contact cannot become an unavoidable second hit. Killing her before Q impact cancels that uncommitted Q; killing her after Q but before E cancels E. An already released sphere continues. Test these exact phase boundaries, including pausing and death.

## 6. Encounter and combat policies

**Opening, mandatory before polishing later systems:** at zero kills, safely introduce a recognizable pursuer-caster and one stand-off caster. By roughly 3–5 seconds, the player should see a champion visibly wind up and launch a recognizable Dodge-family spell while another enemy is approaching. The deadline is a proposed acceptance target measured from start; spawn safety takes priority, but an indefinitely delayed cast fails. Give the first caster a useful starting cooldown and safe position rather than waiting for distant pathfinding. Alternate seeds among Ezreal/Lux/Ahri opening combinations. Do not require kills or a tutorial gate to reveal the mode's defining interaction.

**Pressure:** start with two active foes; ramp by elapsed time toward three or four, majority pursuers when three or more are present. A simple weighted bag prevents long identity starvation and repeated specials. Replace dead enemies after a brief visible spawn warning. All ten identities must be reachable in normal runs over repeated seeds; a deterministic roster browser fixture verifies every row without adding a public test mode. Measure an ordinary short run separately: a debug showcase cannot prove natural cast frequency.

**Durability and contact:** preserve ordinary 112 HP/28 auto baseline initially; tune special HP only if needed, keeping multiple committed autos necessary. Keep per-enemy cooldowns and explicit contact accounting. Start with 40 contact damage/.75s but add an ADC-only shared short contact grace after a displacement/contact impact if needed to prevent simultaneous stacked enemies causing an unavoidable burst. Document its exact duration and test it; never borrow or retune Dodge invulnerability. No passive reward for tanking a melee enemy. Ordinary skillshot starting damage can remain near 24, with special values specified separately.

**Positioning:** pursuers move toward the player between casts, route around obstacles and separate; no attack while spawning. Stand-off bands should normally remain inside Tristana's 275-unit attack reach (initial 210–255), with slower/capped retreat and a post-cast hold. Specials can use brief farther setup but must return to an attackable band. Test edge/corner trapping, obstacle routes, overlap and chase escape. No permanent kiting by an enemy faster than the player. Do not copy Dodge's 330–460-unit Syndra standoff blindly into an ADC with 275 range.

**Threat budget:** begin with at most two live casts, counting windup, outbound, return, split children, delayed impact and displacement recovery as one continuous lifetime per cast. A complex/displacing special initially occupies the whole budget; existing launched effects finish before it is admitted. Regular simple casts may overlap a pursuing enemy. Keep enemies moving and attackable during recovery; avoid long empty-board lessons. Check candidate danger against terrain and a plausible movement escape that includes approaching contact threats. Retry later if unsafe. Sampling is a practical guard, not proof of all-path fairness.

**Commitment/death:** uncommitted casts cancel on caster death; released missiles finish. Delayed ground Q is uncommitted until impact in the preserved ADC policy. Split/return families retain required anchors after death. Each special explicitly defines release and later phases; Orianna Q release does not authorize an R after caster death. Every impact resolves once, with a deterministic death/terminal policy and no state processing after the result screen.

**Attacks/UI:** keep A then click nearest valid enemy to the player in ADC, right-click move/target, S cancellation, F Flash, pause/retry, live-target chase and target-bound projectiles. Maintain one range convention across acquisition/chase/release/range display. QWER remain unavailable without misleading ability names. Show HP, elapsed time, kills, auto hits, target and attack readiness. Results report actual released/hit/cancelled autos and contact/skillshot damage. Do not invent a composite skill score or count ambient hazards as kills.
